# Permute — Free Offline Installer

![Category](https://img.shields.io/badge/Media_Converter-blue?style=flat-square)

## About

Permute is a simple, elegant macOS media converter that converts video, audio, and image files by dragging them onto the app. With support for dozens of formats, automatic device-optimized presets, and batch conversion, Permute handles everyday media conversion needs without complicated settings. Its drag-and-drop simplicity makes it the go-to quick conversion tool for Mac users.

## Common Problems & Limitations

- **macOS Only** — No Windows or Linux version
- **Commercial License** — Paid application
- **Advanced Settings** — Minimal configuration options for users needing precise encoding control
- **FFmpeg Alternatives** — Free FFmpeg front-ends like HandBrake offer comparable conversion
